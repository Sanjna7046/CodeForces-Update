## method 1

making vector to unordered set , to make find function of time complexity 1 s.
```cpp
unordered_set<int> st(v.begin(), v.end());

int h = 0;
for (int i = 0; i < k; i++) {
    if (st.find(i) == st.end())
        h++;
}
```
## method 2  Boolean/Frequency array (Fastest when values are small)

If every value in v lies in a small range (say 0 to 10^6):

```cpp
vector<bool> present(k, false);

for (int x : v)
    if (x < k)
        present[x] = true;

int h = 0;
for (int i = 0; i < k; i++)
    if (!present[i])
        h++;

```
